# bubu_print — téléchargement

[Télécharger l’installateur Windows 0.1.1](https://github.com/fca1/bubu_print_downloads/releases/download/v0.1.1/bubu_print-setup-0.1.1-x64.exe)

[Voir la dernière version disponible](https://github.com/fca1/bubu_print_downloads/releases/latest)

Aucun compte GitHub n’est nécessaire. Télécharger le fichier `.exe` dans les fichiers joints à la release, puis l’exécuter sur chaque PC.

## Prérequis

Windows 10/11 x64, navigateur et Microsoft Word de bureau installé et activé. Python est inclus ; il n’est pas nécessaire de l’installer séparément.

Installation pour l’utilisateur courant, sans droits administrateur. Avant une mise à jour, quitter bubu_print et fermer les modèles ouverts dans Word.

Les documents et réglages sont conservés. Les modèles fournis sont actualisés et les retouches sont préservées dans une copie « personnalisé ».

L’installateur n’est pas signé : Windows peut afficher un avertissement SmartScreen. Son empreinte SHA-256 est fournie avec chaque version.

Ce dépôt contient les fichiers de distribution. Les archives « Source code » proposées par GitHub ne sont pas l’installateur.
